## FAILURES

### F1. Command Palette — duplicate React key `Hand (panning tool)` — FAIL

- **Area:** E — App menus / Command Palette
- **Steps:** Clear console → open Command Palette (Ctrl+P / menu) → inspect DevTools Console
- **Expected:** No React key warnings; Hand appears once in Tools
- **Actual:** Console warning (shown as error in Chrome console UI):

```
Encountered two children with the same key, `Hand (panning tool)`.
Keys should be unique so that components maintain their identity across updates.
```

- **Root cause (code):** `CommandPalette.tsx` adds `actionManager.actions.toggleHandTool` under `toolCommands` **and** also builds commands from `SHAPES` (which includes Hand). Same label used as list key → collision.
- **Impact:** Dev-only React warning today; unsupported reconcile behavior — risk of duplicated/omitted palette rows under future React versions. Does not crash the app in this run.
- **Screenshots:**
  - [tests/ui-command-palette-console-warning.png](./ui-command-palette-console-warning.png)
  - [tests/ui-command-palette.png](./ui-command-palette.png)
- **Console capture:** [tests/console-output.txt](./console-output.txt)
