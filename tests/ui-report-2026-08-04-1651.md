## Highest-risk failures (lead)

### 1. FAIL — Theme toggle crashes the tab
- **Repro:** Main menu → Preferences → Theme (light/dark control)
- **Result:** Chrome **Aw, Snap! Error code: 4**; tab dies. Theme may persist after reload.
- **Retest:** Confirmed again with DevTools closed / single tab.
- **Screenshots:** [`fail-02-theme-toggle-crash.png`](./fail-02-theme-toggle-crash.png), [`fail-05-theme-retest.png`](./fail-05-theme-retest.png), post-reload dark UI [`08-dark-mode-enabled.png`](./08-dark-mode-enabled.png)

### 2. FAIL — Help / keyboard shortcuts crashes the tab
- **Repro:** Main menu → Help, or shortcuts entry (`Shift+?` / `?`)
- **Result:** Immediate **Aw, Snap! Error code: 4**
- **Retest:** Confirmed without DevTools.
- **Screenshots:** [`fail-03-keyboard-shortcut-crash.png`](./fail-03-keyboard-shortcut-crash.png), [`fail-06-shortcuts-retest.png`](./fail-06-shortcuts-retest.png)

### 3. FAIL — Export image dialog crashes the tab
- **Repro:** `Ctrl+Shift+E` / Export image
- **Result:** Immediate **Aw, Snap! Error code: 4**
- **Screenshot:** [`fail-07-export-crash.png`](./fail-07-export-crash.png)

### Pattern
Crashes cluster on specific overlay/dialog surfaces (theme control, Help/shortcuts, Export). Other overlays (command palette, live collaboration modal, library, main menu, style panel, minimap) worked. Treat as **FAIL for those controls in this environment**; root cause may be app rendering/GPU path or Chromium renderer kill (`Error code: 4`) under dialog load — not confirmed as minimap-specific.

## Areas not testable (and why)

1. **Image upload** — OS file picker not reliably driveable here.  
2. **Save/Open to disk** — native file dialogs.  
3. **Live collaboration session** — would require starting a remote session / network identity; entry UI only.  
4. **Export completion** — dialog open crashes before export UI can be used.  
5. **Screen recording artifact** — `RecordScreen` SAVE timed out in this environment; stills under `tests/` are the primary evidence.

## Coverage honesty

- Required surfaces were exercised in a real browser against a live Vite server.  
- Failures above are **not swallowed**: theme, help/shortcuts, and export are loud FAILs with screenshots.  
- Incomplete depth called out as SUSPECT/NOT TESTABLE rather than silent PASS.  
- **PR #14 minimap feature itself: PASS** in this run. Broader app stability regressions above may or may not be introduced by this PR; bisect against `master` was not completed in this pass.

## Recommendation

1. Treat theme / Help / Export crashes as merge blockers until reproduced outside this agent browser or fixed.  
2. Minimap UX looks good (overlay, nav, close).  
3. Re-run export/help/theme on a developer desktop Chrome to confirm whether `Error code: 4` is environment-specific GPU/renderer behavior.
